# AEM Home / Experience Hub

## Project Brief

Experience.adobe.com grew organically over years. Now it's a mess. Four different personas, dozens of disconnected use cases, and no coherent way to navigate between them. New users don't get an aha moment. Existing users lose time finding what they need. Competitors use this friction against us in the market.

This project fixes that. We're rebuilding experience.adobe.com as "AEM Home," a unified, role-aware entry point for all AEM users, with an embedded AI assistant (Experience Hub) that gets users to value faster.

Zen statement: "Create a home for all Experience Manager users to start an intuitive content creation journey and unlock their creative potential."

## Goal

Reduce friction and time-to-value for all AEM users by creating a personalized, role-based home that surfaces the right tools, tasks, and AI assistance at the right moment.

Success looks like: users land, orient immediately, and take action without hunting.

## Audience

| Persona | Primary Need |
|---|---|
| Marketers | Content creation, asset optimization, insights via Success Studio |
| Developers | Build tools, BPA, CAM, migration support, pipeline management |
| System Administrators | Provisioning, permissions, entitlements |
| Business Owners | License reporting, governance, production oversight |

## Scope

**AEM Home (Project Basecamp)** — Unified landing page replacing the fragmented Cloud Manager experience. Features include role-based navigation, recents, tasks, quick actions, AEM Assistant, and personalization. The homepage is the initial touchpoint for new users and the daily driver for everyone else.

**Experience Hub (AI Assistant)** — Five embedded agents surfaced through the Prompt Library Platform. Discovery, optimization, development, production, and governance. Currently in phased rollout with 3 of 5 agents live.

**Prompt Library Platform** — Backend infrastructure for curating and serving contextual AI prompts across AEM and Adobe Experience Platform. Has an admin UI for prompt management and an end-user interface embedded inside the AI Assistant. Includes intelligent search, similarity detection, role-based filtering, and B2B/B2C customer type detection.

## Current Status

3 of 5 agents live (discovery, optimization, development). Production and governance agents in progress. Prompt inventory sourced from Grafana usage data as of Feb 19, 2026. Prompt Library Platform in MVP with admin-only write access.

## SD Angle

This is not a feature. It is a platform reorganization that touches every AEM persona and every product surface.

The Senior Director contribution here is cross-org influence: aligning Developers, Marketers, Sysadmin, and Business Owner workflows under one coherent entry point while driving AI agent adoption through thoughtful prompt design and role-based personalization.

Three things that make this visible upward:

**Competitive impact.** The current fragmentation is an active sales disadvantage. Fixing experience.adobe.com has a measurable effect on win rates and retention. This is a business outcome, not just a UX improvement.

**Platform thinking.** The Prompt Library is infrastructure, not a feature. It compounds across AEM and AEP. Building it once and reusing it across surfaces is the kind of leverage that Senior Directors think about.

**AI strategy with judgment.** Leading a phased five-agent rollout with structured governance and a real prompt curation system shows strategic judgment, not just execution speed. The decision to ship 3 of 5 agents before the others reflects prioritization under constraint.

The story to tell upward: this project gives AEM a front door. Before this, AEM was a collection of tools. After this, it is a product with an identity.
