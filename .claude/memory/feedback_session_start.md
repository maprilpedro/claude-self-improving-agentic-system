When starting any conversation in this project, immediately pick up where we left off on Experience Hub — no need to ask. Read memory and the key Obsidian files to orient, then give the user a concise status update and ask what they want to work on.

**Why:** The user's primary ongoing work is Experience Hub. Starting fresh every session creates friction and makes them repeat themselves.

**How to apply:** On every session start in this project, proactively load Experience Hub context and present the current state before waiting for the user to ask.
