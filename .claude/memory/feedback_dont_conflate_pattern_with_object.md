When two artifacts use the same architecture *sentence shape* ("a central thing, consumed by all agents, not re-implemented per harness"), that is NOT evidence they are the same thing or that one encroaches on the other. Compare the **object**, not the phrasing.

**The miss (2026-05-29):** I told Pedro his published blog (`From North Star to There Waiting`) was in direct lane-conflict with Daniel Mrose's Enterprise Ground Truth (EGT), and the memory's RESUME-HERE block carried a 🔴 "lane-encroachment" alarm. Pedro pushed back three times ("est-ce que c'est la même chose"). When I finally read **both source artifacts side by side**, they were different layers: the blog = skills declaration + surface-consistency; EGT = brand-context data. EGT is a brick that *feeds* the blog's layer, not a competitor. The "overlap" was me pattern-matching Andrei's verbatim line onto Pedro's thesis without checking the object.

**Why:** Architecture patterns (centralize, expose via MCP, consume everywhere) are generic. Many distinct products share them. Competitive-threat calls drive real political moves (recadrer with Bertrand, route via Ian) — a false alarm wastes a senior leader's capital and credibility. **Les gagnants pensent en termes de probabilité, pas de certitude** — I overclaimed certainty from one quote.

**How to apply:**
1. Before calling overlap/encroachment, **read both artifacts in full**, not memory summaries. Memory is point-in-time and can itself carry an old mis-read.
2. Separate **pattern** (how it's built) from **object** (what it operates on: data vs skills vs surfaces vs orchestration). Overlap requires same object, not same pattern.
3. State confidence honestly. "Same sentence shape, object unverified" ≠ "same thing."
4. When Pedro repeats the same question, treat it as a signal I haven't actually verified — go to source. See [[feedback-confirm-ask-before-producing]].
5. Check what was actually *demoed* vs *narrated* — "for all our agents" was Daniel's narration; only Governance + a website-gen team actually consumed EGT. Look for the dogs that don't bark.
