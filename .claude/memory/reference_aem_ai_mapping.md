**AEM AI Mapping** = Pedro's surface-map of AEM agent surfaces, on Confluence (space `~pedrofer`). One intake page per surface; the surface **owner fills their own** (= consolidation-into-Pedro's-platform, Varun pattern; Pedro owns the canonical definition). Launched 2026-06-03.

Each intake captures: what the surface is / status / personas / contexts / the harness / **capabilities + maturity** (Concept → In development → Alpha → Beta → GA — the "production-ready" view Martin Buergi asked for) / skills authorship + selection / chat UI + memory / ownership (who owns what) / where the surface lands on the **6 architecture divergences** (harness count, who picks skills, build-vs-check consistency, marketplace-vs-git distribution, chatbox-vs-purpose-built UI, customer-skills-in-harness).
